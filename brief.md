# Weekend Project: Personal Portfolio Page

## Overview

Your task is to build a **personal portfolio webpage** using only HTML and CSS.
The HTML skeleton has been provided for you. Your job is to write all the CSS from scratch.

This project brings together everything you have learned across the course:
selectors, the box model, typography, colors, flexbox, grid, positioning, and responsive design.

---

## What You Are Building

A single-page portfolio website with the following sections:

### 1. Navbar
- Your name or a logo on the left
- Navigation links on the right (Home, About, Skills, Projects, Contact)
- The navbar should **stick to the top** of the page as the user scrolls

### 2. Hero Section
- A full-width section with a background color or background image
- A large heading (your name or a tagline)
- A short subtext (one sentence about yourself)
- A call-to-action button (e.g. "View My Work" or "Get In Touch")

### 3. About Section
- A profile photo (you can use a placeholder image from https://placehold.co) on one side
- A short paragraph about yourself on the other side
- The photo and text should sit **side by side** on desktop

### 4. Skills Section
- A grid of at least **6 skill cards** (e.g. HTML, CSS, Git, Figma, etc.)
- Each card should have a visible hover effect

### 5. Projects Section
- At least **2 project cards**, each with:
  - A cover image (placeholder is fine)
  - A project title
  - A short description
  - A "View Project" link/button
- Cards should be arranged in a grid

### 6. Contact Section
- At least **3 social/contact links** (e.g. GitHub, LinkedIn, Email)
- Links should be styled as buttons or icon-style links

### 7. Footer
- Your name and a copyright year
- Content should be centered

---

## Requirements

| # | Requirement |
|---|-------------|
| 1 | All styling must be written in a **separate CSS file** (`style.css`) — no inline styles |
| 2 | Use at least **one Google Font** for typography |
| 3 | The page must be **fully responsive** — it should look good on both mobile and desktop |
| 4 | Use a **mobile-first approach** with media queries for larger screens |
| 5 | The navbar must use **Flexbox** for layout |
| 6 | The skills section must use **CSS Grid** |
| 7 | The projects section must use **CSS Grid** |
| 8 | No CSS frameworks allowed (no Bootstrap, Tailwind, etc.) |
| 9 | No JavaScript |
| 10 | Submit a folder containing `index.html` and `style.css` |

---

## Suggested Folder Structure

```
your-name-portfolio/
├── index.html
├── style.css
└── images/         (optional, for any local images)
```

---

## Tips

- Start with the mobile first or desktop first and make it responsive as you progress.
- Use CSS custom properties (variables) for your colors and fonts — it keeps things tidy.
- The `position: sticky` property is your friend for the navbar.
- For the side-by-side About layout, either Flexbox or Grid works.
- Don't overthink the design — focus on writing clean, correct CSS.
